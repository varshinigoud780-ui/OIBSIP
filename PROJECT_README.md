# Random Password Generator

## Project Description
A Python-based Random Password Generator with a graphical user interface (GUI) built using Tkinter.

## Features
- Generate random passwords
- Choose password length
- Include uppercase letters
- Include lowercase letters
- Include numbers
- Include special characters
- Copy the generated password
- Simple and user-friendly GUI

## Technologies Used
- Python
- Tkinter
- String module
- Secrets module

## How to Run
1. Install Python on your computer.
2. Open the project in PyCharm or any Python IDE.
3. Run `main.py`.
4. Use the GUI to generate a password.

## Project File
- `main.py` – Main Python source code

## Output
The application displays a graphical interface for generating random passwords.
